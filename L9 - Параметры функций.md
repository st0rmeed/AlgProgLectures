<h3 style='margin-bottom:0.5em;'>Пример передачи параметра по ссылке</h3>
```cpp
int sum(int &a, int &b){
	return a+b;
}

int c=5, d=6;
sum(c, d); // 11
sum(5, 6); // error, нельзя делать ссылки на rvalue
```




<h3 style='margin-bottom:0.5em;'>Выражения в качестве параметров</h3>При вызове функции с параметром в виде сложного выражения, параметр должен быть заранее вычислен
<div style='margin-bottom:0.5em;'></div>
```cpp
int sum(int &a, int &b){
	return a+b;
}

int div(int *a, int *b){
	return *a / *b
}

int c=5, d=6;
int res = div(&c, &d); // ok
res = sum(c+d, div(&c, &d)); // error, не создаться ссылка на `c+d`
res = sum(c, (cin >> d, d)); // ok, оператор запятая вернет `l-value`, откинув потоковый ввод до нее
```




<h3 style='margin-bottom:0.5em;'>Реализация функций</h3>
***Определение длины строки***
<div style='margin-bottom:0.5em;'></div>
```cpp
int string_length(char *arr){ // или (char arr[])
	int length = 0;
	while(arr[length] != '\0'){ // важно заключить именно в одинарные кавычки, т.к. это символ окончания строки
		length++;
	}
	return length;
}
```

***Копирование строки***
<div style='margin-bottom:0.5em;'></div>
```cpp
void copy_string(char arr[], char copy_arr[]) { // массив - указатель на его первый элемент, поэтому по факту мы работаем с указателями
    int length = string_length(arr);
    for (int i = 0; i <= length; i++) {
        copy_arr[i] = arr[i];
    }
}

int main(){
	char string[10] = "sdfsdf", copied_string[10];
	copy_string(string, copied_string);
}
```




<h3 style='margin-bottom:0.5em;'>Передача массивов в качестве параметров</h3>
Как раннее говорилось, когда мы передаем в функцию массив, то мы фактически передаем указатель на первый элемент массива. Поэтому если внутри функции вызвать код `sizeof(arr)`, то он будет эквивалентен `sizeof(*arr)` и вернет размер элемента, на который ссылается указатель - то есть, на первый элемент массива




<h3 style='margin-bottom:0.5em;'>Передача в функцию ссылки на массив</h3>
Имя ссылки - псевдоним самого массива, а не указатель. Когда в функцию передаем ссылку на массив - мы передаем адрес массива (но не указатель!)
<div style='margin-bottom:0.5em;'></div>
При использовании ссылок на массивы, должны указываться все размерности (причина - тип ссылки должен точно соответсвовать типу массива, а размерность массива - часть его типа)
<div style='margin-bottom:0.5em;'></div>
```cpp
//arr.h
const int N=4, M=5;
```
<div style='margin-bottom:0.5em;'></div>
```cpp
//arr.cpp
#include "arr.h"
int f(int (&arr)[N], int (&darr)[N][M]){
	sizeof(arr); // 4 * 4 байта = 16 байта
	sizeof(darr); // 5 * 16 байт = 80 байт
}
```

*Примечание:* скобки внутри функции играют ключевую роль, без них запись `int & arr[n]` будет обозначать массив из ссылок на `int` (из-за приоритета операций), а так - ссылка на массив элементов `int`




<h3 style='margin-bottom:0.5em;'>Функции с параметрами по умолчанию</h3>
Концепия точно такая же, как в `python` - использование значения по умолчанию при отсутствии переданного параметра для избежания ошибки
<div style='margin-bottom:0.5em;'></div>
```cpp
int k(int q, char c){
	// <полезный код>;
}

int f(int q, char c='x'){
	// <полезный код>;
}

k(5); // error, missing arugment `c`
f(5); // ok
```

Опускать список фактических параметров при вызове функции можно только подряд с конца списка параметров, поскольку компилятор не будет понимать, какой из параметров был опущен
То есть при определении функции должно выполняться правило: если параметр имеет значение по умолчанию, то все параметры справа от него тоже должны иметь значения по умолчанию
<div style='margin-bottom:0.5em;'></div>
Значения по умолчанию должны указываться при объявлении функции, т.к. компилятор видит только прототип функции при вызове самой функции




<h3 style='margin-bottom:0.5em;'>Перегрузка имен функций</h3>
Перегрузка имен функций - это возможность создавать несколько функций с одинаковым именем, но разными наборами параметров. При этом компилятор сам выбирает, какую функцию ему вызвать (исходя из переданных параметров)
<div style='margin-bottom:0.5em;'></div>
```cpp
int sum(int a, int b){
	return a + b;
}

int sum(int a, int b, int c){
	return a + b + c;
}

sum(2, 2); // ok
sum(7, 7, 7); // ok
```

Важный нюанс - нельзя писать перегрузку, где изменяется только тип возвращаемого значения. Компилятор не сможет определить, какую функцию вызвать, ведь аргументы одинаковые, а возвращаемый тип - разный




<h3 style='margin-bottom:0.5em;'>Рекурсивные функции</h3>
Рекурсивные функции - функции, вызывающие сами себя. Их главное достоинство заключается в возможности написания компактного кода
<div style='margin-bottom:0.5em;'></div>
Следует избегать создания локальных переменных внутри области рекурсивной функции, поскольку каждая функция создает свой стек $\rightarrow$ большой расход памяти. То есть вместо `result = n*f(n); return result` внутри функции лучше следует написать `return n*f(n)`




<h3 style='margin-bottom:0.5em;'>Возвращаемые значения</h3>
Возвращаемые функцией значения могут быть
- адресами (указателями/ссылками)
- базовым типом
- кастомным типом

При этом при возврате адресов стоит учесть, что будет возвращен адрес локальной переменной, которая удаляется после выхода из функции
<div style='margin-bottom:0.5em;'></div>
```cpp
char *f1(){ // ф-я, возвращающая указатель на `char`
	char arr[] = "777";
	return arr; // автоматически указатель на первую `7`
}

int &f2(){ // ф-я, возвращающая ссылку на `int`
	int value=5;
	return value;
}

int array = f1(); // будет хранить адрес переменной, которая удалена - неопределенное поведение
char num = f2();
```

При этом можно возвращать
- адрес объекта, который находится за пределами области функции (т.е. в области, из которой вызывают другую функцию)
- адрес объекта со статическим временем существования
- указатель на строковый литерал (важно наличие `const` перед началом фунции, т.е. `const char* f()`)
- указатель на динамически созданный объект




<h3 style='margin-bottom:0.5em;'>Реализация инкремента посредством функций</h3>
```cpp
int post_inc(int &x){
	int tmp = x;
	x++;
	return tmp;
}

int &prefix_inc(int &x){
	++x;
	return x;
}
```




<h3 style='margin-bottom:0.5em;'>Возвращение указателя на многомерный массив</h3>
```cpp
int (*f())[20]{
	static int arr[10][20];
	return arr; // в функциях имя массива автоматически преобразуется в указатель на его первый элемент
}

int (*p)[20] = f(); // переменная p, которая является указателем на массив из 20 интов
```
<div style='margin-bottom:0.5em;'></div>
*Читаем по правилу спирали*
1. `f` - переменная, которая...
2. `f()` - ..., которая является функцией, возвращающей...
3. `*f()` - ..., возвращающей указатель на...
4. `(*f())[20]` - ... на массив, состоящий из двадцати элементов...
5. `int (*f())[20]` ... двадцати интов

Нетрудно заметить несосытковку при чтении: по факту мы возвращаем `int arr[10][20]={{int, int, ...}, {int, int...}, ...}`, а пишем, что возвращаем массив из 20 интов. Тонкость заключается в том, что функция возвращает указатель не на весь двумерный массив, а только на его первую строку
<div style='margin-bottom:0.5em;'></div>
По факту, когда мы возвращаем массив `arr`, то функция возвращает указатель на 1-ый элемент массива, в нашем случае - другой массив из двадцати интов

Возникает вопрос: как переменная, в которую записывается результат функции, узнает, что после 1-го массива есть еще 9 точно таких же массивов? Ответ: а никак)) Мы можем обращаться впринципе хоть к 20 массиву после нашего 1-го исходного, просто будет неопределенное поведение




<h3 style='margin-bottom:0.5em;'>Функции с переменным числом параметров</h3>
Язык `c`/`cpp` допускает функции, где количесвто параметров в программе может изменяться, признаком такой функции является наличие многоточия `...`. У такой функции должен быть хотя бы один обязательный параметр
<div style='margin-bottom:0.5em;'></div>
Встретив многоточие в программе, компилятор прекращает проверять соответствие типов параметров
<div style='margin-bottom:0.5em;'></div>
```cpp
int func1(int a, ...);
int func2(int a, const char *, ...)

func1(4, 5, 3); // ok
func2(4); // error, missing 1 argument
func2(4, "777"); // ok
```
<div style='margin-bottom:0.5em;'></div>
Работа со переменным числом аргументов представлена ниже

Конкретный пример функции с переменным числом параметров, у которой в качестве первого параметра передается количество дополнительных аргументов типа `int` и которая должна вернуть сумму аргументов
```cpp
int sum(int count, ...){
	va_list args;
	va_start(args, count);
	
	int result = 0;
	for (int i=0; i<count; i++){
		result += va_args(args, int);
	}
	
	va_end(args);
	
	return result
}
```
<div style='margin-bottom:0.5em;'></div>
В этом примере
- `va_list` - специальный тип, предназначенный для доступа к дополнительным параметрам, является универсальным указателем
- `args` - переменная, которая че-то типа генератора на питончике
- `va_start(args, count)` - запускает чтение и связывает переменную `args` с первым переменным параметром, стоящим после крайнего обязательного параметра `count`
- `va_arg(args, int)` - формирование текущего элемента и сдвиг на следующий
- `va_end(args)` - завершение чтения, обнуление универсального указателя

Все вышеописанное из стандартной библиотеки `stdarg`




<h3 style='margin-bottom:0.5em;'>Указатель на функцию</h3>
Указатель на функию содержит стартовый адрес функции, а его тип зависит от количества параметров и от возвращаемого значения. Адрес функции - это имя функции, которые мы задаем ей при определении
<div style='margin-bottom:0.5em;'></div>
```cpp
int max(int a, int b);
int min(int a, int b);

int (*p_func)(int, int) = max; // указатель на функцию max
int *p_func(int, int) = max; // функция p_func(int, int), которая вощвращает указатель на `int`

// ниже две эквивалентных записи
p_func = max; // в данном контексте `max` преобразуется в указатель
p_func = &max;
```
<div style='margin-bottom:0.5em;'></div>
*Читаем по правилу спирали* (2-ую строчку с объявлением указателя)
1. `p_func` - переменная, которая...
2. `p_func(int, int)` - ..., которая является функцией, принимающей на вход два числа типа `int` и...
3. `int *p_func(int, int)` - ... и возвращающая указатель на `int`

*При инициализации* имя функции `max` преобразуется в указатель на эту функцию, поэтому можно переписать так: `int (*p_func)(int, int) = &max;` то есть здесь записи `&max` и `max` будут эквивалентны


*Вызов функции по указателю*
<div style='margin-bottom:0.5em;'></div>
```cpp
int (*p_func)(int, int) = max;

// ниже две эквивалентных записи
int y = p_func(2, 2); 
y = (*p_func)(2, 2); 
```
<div style='margin-bottom:0.5em;'></div>
*Читаем по правилу спирали*
1. `p_func` - переменная, которая...
2. `*p_func` - ..., которая является указателем на...
3. `*(p_func)(int, int)` - ... на функцию, принимающую на вход два `int` и...
4. `int (*p_func)(int, int)` ... и возвращающую `int`


*Массивы указателей на функции*
<div style='margin-bottom:0.5em;'></div>
```cpp
int (*arr_func[])(int) = {sin, cos, tg};

int res = arr_func[i](1);
res = (*arr_func[i])(1);
```
<div style='margin-bottom:0.5em;'></div>
В этой записи (по правилу спирали)
1. `arr_func` - переменная, которая...
2. `arr_func[]` - ..., которая является массивом...
3. `*arr_func[]` - ... массивом из указателей...
4. `(*arr_func[])()` - ... из указаталей на функции, которые...
5. `(*arr_func[])(int)` - ... которые принимают на вход `int` и ...
6. `int (*arr_func[])(int)` - ... и возвращают `int`
