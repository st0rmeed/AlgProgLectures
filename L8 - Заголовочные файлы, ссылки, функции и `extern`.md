<h3 style='margin-bottom: 0.5em;'>Ключевое слово `extern`</h3>
Используется для того, чтобы сообщить компилятору, что переменная (функция) определена в другом модуле
<div style='margin-bottom: 0.5em;'></div>
```cpp
// utils.cpp
#pragma once // защита от повторного импорта
int x; 
int arr[10][20];
int add(int a, int b);
```
<div style='margin-bottom: 0.5em;'></div>
```cpp
// realization.cpp
int add(int a, int b){
	return a+b;
}
```
<div style='margin-bottom: 0.5em;'></div>
```cpp
// main.cpp
extern int x;
extern arr[][20]; 
```
<div style='margin-bottom: 0.5em;'></div>
Если переменная с таким именем не была определена в программе, то возникает ошибка при *линовке* (от слова `linking` - этап компоновки, на котором отдельные скопилированные файлы и библиотеки объединяются в единый исполняемый файл или библиотеку)

Массив объявлений с ключевым словом `extern` должен содержать информацию обо всех младших размерностях. Собственно, как и при определении обычного массива. Однако в динамических массивах все с точностью наоборот - нужно обязательно указать длину первого уровня массива, но можно опустить длину вложенного уровня
<div style='margin-bottom: 0.5em;'></div>
*Обьяснение этому простое*
- *статический массив* в памяти лежит как одна длинная сплошная линия (одномерный массив), и чтобы найти элемент `matrix[i][j]` программе нужна формула `индекс_строки * длина_строки + индекс_столбца`, ее невозможно посчитать без знания длины вложенного уровня
- *динамический массив* - это не единый блок, а массив указателей на другие независимые массивы; чтобы создать главный массив указателей программе нужно знать только собственную длину массива




<h3 style='margin-bottom: 0.5em;'>Заголовочные файлы</h3>
Позволяют эффективно работать с функциями стандартной (`#include <standart.h>`) и сторонних (`#include "other.h"`) библиотек
<div style='margin-bottom: 0.5em;'></div>
Задаются директивой препроцессора `#include`, могут содержать в себе описания зависимостй, объявления внешних переменных и констант, директивы условной трансляции и макроопределения, перечисления и определение встроенных `inline` функций 
<div style='margin-bottom: 0.5em;'></div>
*Примечание*: обычно в заголовочных файлах пишут только заголовки (прототипы) функций, а их код выносят в отдельный `.cpp` файлы. В `inline` функциях код пишется прямо в `.h` файле

*Виды заголовочных файлов*
1. Пользовательские
2. Библиотечные
   - стандартная библиотека
   - системные (`шиндовс`/`линукс`)
   - `Qt` - графический интерфейс

*В заголовочных файлах не должно быть*
- определения невстроенных функций
- определения данных
- неименованных простарнств имен `namespace {}`


*Пример хорошего кода импорта переменной*
<div style='margin-bottom: 0.5em;'></div>
```cpp
// server.cpp
int x;   // сам процесс выделения памяти
```
<div style='margin-bottom: 0.5em;'></div>
``` cpp
// server.h
extern int x;
```
<div style='margin-bottom: 0.5em;'></div>
```cpp
// client1.cpp
#include <server.h>

/*
	<полезный код>
*/
```


*У препроцессора `#include` (работает как копипаст) есть несколько форм записи*
1. `#include <iostream>` - для стандартных библиотек
2. `#include "other.h"` - для пользовательстких
3. `#include MACRO` - для макросов соответственно

Для защиты от повторного подключения файла можно использовать
- `#pragma once` - гарантирует одиночное подключение файла
- через страж включения (он пишется в файле, который мы можем несколько раз подключить)
- <div style='margin-bottom: 0.5em;'></div>
  ```cpp
  #ifndef SECOND_H
  #define SECOND_H
  
  /*
	<полезный код>
  */
  
  #endif
  ```




<h3 style='margin-bottom: 0.5em;'>Ссылки `references`</h3>
***Ссылки типа l-value***
В языке `cpp`, в отличии от языка `c`, существуют ссылки - это псевдонимы для уже существующей переменной `l-value`. В отличии от указаталей обязательно инициализируются при создании, не являются отдельными переменными и не занимают место в памяти
<div style='margin-bottom: 0.5em;'></div>
```cpp
int value = 1;

int *p; // инициализируем пустой указатель
int &ref; // error, т.к. не осуществляется инициализация ссылки
void &ref; // error, сам по себе тип `void` подразумевает отсутствие типа
extern double &ref; // ok, т.к. осуществляется определение ссылки, а не ее обьявление (т.е. мы просто говорим компилятору, что где-то там объявлена `ref`)

int *p = &value; // указатель смотрит на переменную `value`
int &ref = value; // ссылка на `value`, здесь символ `&` означает не взять адрес, а создать ссылку (!)

int *&ptr_ref = p; // ссылка на указатель
```

*Инкрементирование значение по ссылке и указателю*
<div style='margin-bottom: 0.5em;'></div>
```cpp
(*p)++; 
ref++; // работаем как с обычной переменной
```

*Изменения адреса ссылки на другую переменную вызовет ошибку*
<div style='margin-bottom: 0.5em;'></div>
```cpp
int val1=0, val2=1;
int &ref = val1;
int &ref = val2; // error
```


***Ссылки типа r-value***
Предназначены для привязки исключительно к временным объектам. В отличии от `l-value` ссылок, занимают место в памяти. Основная цель - реализация семантики перемещения значения у "умирающего объекта" вместо его дорогостоящего копирования
<div style='margin-bottom: 0.5em;'></div>
```cpp
int **pP = &p; // указатель на указатель
int &&ref2 = ref; // ссылка на ссылку 
```
<div style='margin-bottom: 0.5em;'></div>
```cpp
int &r1 = 1; // error, т.к. ссылка `r-value`
const int &r2 = 5; // ok, `const` скрытно создает место в памяти
int &&r3 = 7; // ok, т.к. является `l-value`
```

*Ссылки на указатели*
<div style='margin-bottom: 0.5em;'></div>
```cpp
int val = 1;
int *p = &val;

int *&refP = p; // ok
*refP = 3.3; // ok

int *&refM = &d; // error, т.к. `&d` возвращает адрес переменной в виде временного значения r-value
```

*Связь `sizeof()` и ссылок*
<div style='margin-bottom: 0.5em;'></div>
```cpp
int d;
int *p = &d;

sizeof(p); // размер указателя
sizeof(*p); // размер переменной `d` типа int

int &ref = d;
sizeof(ref); // размер переменной `d` типа int
```




<h3 style='margin-bottom: 0.5em;'>Функции</h3>
*Основные назнчения функций*
- улучшение читаемости и структуры
- выполнение одних и тех же действий с разными наборами данных
- использование чужого кода посредством функций

*Использование функции состоит из 3-х частей*
- объявление (прототип)
- определение (реализация, тело функции)
- вызов функции

*Общий вид использования*
<div style='margin-bottom: 0.5em;'></div>
```cpp
// server.h
int func();    // объявление
```
<div style='margin-bottom: 0.5em;'></div>
```cpp
// server.cpp
int func(){    // определение
	// <...>
}
```
<div style='margin-bottom: 0.5em;'></div>
```cpp
// main.cpp
#include "server.h"
func();   // вызов
```




<h3 style='margin-bottom: 0.5em;'>Объявление функции</h3>
```cpp
[спецификатор] [тип] [соглашение_по_вызову] имя_функции([список_аргументов] или [void]); 
```

***Спецификатор***
- `extern` - объявление функции с внешним вызовом, т.е. функция может быть определена в другом файле программы (можно опустить этот спецификатор, запись будет эквивалентна)
- `inline` - подсказка, что функцию можно встроить непосредственно в место вызова (как в блядском блокнотике при помощи `ctrl-c`, `ctrl-v`) вместо того, чтобы каждый раз переходить в другую область памяти
- `static` - функция имеет внутреннее связыавние, т.е. обращаться к ней по имени можно только из этого же `.cpp` файла, но можно вызвать через импорт или по ссылке

***Тип*** указывает на то, какими будут возвращаемые функцией данные. При этом `void` означает, что функция ничего не вернет
Если передаваемая переменная не используется, то можно не указывать ее имя, например
<div style='margin-bottom: 0.5em;'></div>
```cpp
int func(int a, int){ //ok
	return a;
}
```

***Соглашение по вызову*** определяет место размещение аргументов (в стеке или в регистре), отвечающего за очистку стека. Вручную указывать обычно не требуется

***Список аргументов***
Если функция в `c` определена `int func()` - это не значит, что она ничего не принимает. Это значит, что количество и типы аргументов не определены
Чтобы указать, что функция ничего не принимает используется `int func(void)`
<div style='margin-bottom: 0.5em;'></div>
А в `cpp` наоборот: `int func()` - функция без параметров




<h3 style='margin-bottom: 0.5em;'>Определение функции</h3>
Время жизни переменных внутри функции эквивалентно времени жизни переменных в области видимости блока. Имена формальных параметров в определении и объявлении могут различаться, а в объявлении и вовсе могут отсутствовать
<div style='margin-bottom: 0.5em;'></div>
Вложенные функции не допускаются, а возврат значения осуществляется `return`
<div style='margin-bottom: 0.5em;'></div>
Имя функции - указатель на начало блока выполнения команд (по аналогии с массивами, где имя массива - адрес первого элемента)

<h3 style='margin-bottom: 0.5em;'>Возвращаемые значения</h3>
Если функция ничего не возвращает (`void`), то она может быть прервана инструкцией `return;` в любой момент
<div style='margin-bottom: 0.5em;'></div>
Если в процессе вычислений получиось значение, которое отличается от значения, возвращаемого функцией, то выражение может быть приведено к нужному типу (например, функция `int f()` вернет `15`, если при подсчете получилось `15.7`)




<h3 style='margin-bottom: 0.5em;'>Встроенные функции</h3>
Такими функциями называются те, что определены со спецификатором `inline`. Они иключают накладные расходы на вызов функции, сохранение контекста, но увеличивают объем исполняемого файла. Принцип заключается в простой подстановке кода в место вызова
<div style='margin-bottom: 0.5em;'></div>
При описании такой функции, объявление должно быть совмещено вместе с определением и обычно содержиться в `.h`
<div style='margin-bottom: 0.5em;'></div>
Ключевое слово `inline` является для компилятора рекомендацией, а не приказом. То есть он может его проигнорировать

С их помощью можно заменять макросы
<div style='margin-bottom: 0.5em;'></div>
```cpp
#define MAX(x, y) ((x)>(y)? (x): (y))
inline int max(int x, int y) {return x>y? x: y;}
```




<h3 style='margin-bottom: 0.5em;'>Способы передачи аргументов</h3>
- *по значение* - когда требуется сохранить исходное передаваемое значение в функцию
- *по адресу (ссылка/указатель)* - функция получает не копию объекта, а его адрес и работает с ним напрямую

*Передача по значению*
<div style='margin-bottom: 0.5em;'></div>
```cpp
void change(int a, int b){
	a = 5; b = 7;
}

int x=1, y=11;
change(x, y);
```

*Передача по ссылке*
```cpp
void change (int &a, int&b);{
	a = 5; b = 7;
}

int x=2, y=22;
change(x, y);
```

*Передача через указатель*
```cpp
void change(int *a, int *b){ // принимает адреса переменных
	*a = 5; *b = 7;
}

int x=3, y=33;
change(&x, &y);
```
