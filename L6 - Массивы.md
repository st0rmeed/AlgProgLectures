<h3 style='margin-bottom: 0.5em;'>Массив</h3>
Массив - это совокупность упорядоченных элементов, бывают одномерные, двумерные, трехмерные и т.д.
<div style='margin-bottom: 0.5em;'></div>
```cpp
type name[ndim];
```

*Элементы одного массива должны быть*
- одного типа
- занимают непрерывную область памяти
- пронумерованы, начиная с `o`
<div style='margin-bottom: 0.65em;'></div>
*Допступ к элементам массива осуществляется*
- с помощью оператора `[]`
- посредством операторы разыменования
<div style='margin-bottom: 0.65em;'></div>
Массив может локальным, глобальным, статическим или из пространства имен. При инициализации необходимо указать размерность массива, иначе - ошибка (кроме случаев, когда задан список инициализации)
<div style='margin-bottom: 0.65em;'></div>
Нельзя инициализировать размеры массива с помощью обычной переменной, только с помощью препроцессора или `const`
<div style='margin-bottom: 0.65em;'></div>
Для повышения эффективности кода, компилятор не контролирует выход за границы массива при обращении к элементам




<h3 style='margin-bottom: 0.5em;'>Инициализация массива</h3>
Выделяют явную (когда программист задает конкретные элементы массива) и неявную инициализацию
<div style='margin-bottom: 0.5em;'></div>
```cpp
int arr[3] = {1, 2, 3, 4}; // error
int arr[3] = {1, 2}; // [1, 2, 0]
char arr[4] = {'a', 'b'}; // ['a', 'b', '\0', '\0']
char arr[3] = {"ab"}; // ['a', 'b', '\0']
char arr[3] = "ab"; // ['a', 'b', '\0']
char arr[3] = "abc"; // error - нехватка места, т.е. еще "\0"
```
<div style='margin-bottom: 0.5em;'></div>
```cpp
int arr[2][3] = {1, 2, 3, 4, 5, 6} // {{1, 2, 3}, {4, 5, 6}}
int arr[2][3] = {{1}, {4, 6}} // {{1, 0, 0}, {4, 6, 0}}
```

Если инициализация массива происходит с одновременнем присвоением ему значения, то старшую размерность можно опустить
<div style='margin-bottom: 0.5em;'></div>
```cpp
char string[] = "qwerty"; // ok
char string2[] = {'q', 'w', 'e', 'r', 't', 'y'}; // ok
int arr[][3] = {
	{0, 1},
	{10},
	{20, 30, 40}
}; // ok
```
<div style='margin-bottom: 0.5em;'></div>
Однако следующий код вызовет ошибку (из-за разных длинн вложенных массивов; из-за появления сложной математики при поиске элемента)
<div style='margin-bottom: 0.5em;'></div>
```cpp
int error_arr[][] = {{1, 2}, {3, 4}}; // error
int error_arr2[2][] = {{1, 2}, {3, 4}}; // error
```




<h3 style='margin-bottom: 0.5em;'>Особенности инициализации массивов</h3>
В `cpp` имя массива является константным указателем на его первый элемент, поэтому следующий код выдаст ошибку
<div style='margin-bottom: 0.5em;'></div>
```cpp
int arr[5];
arr = {1, 2, 3} // error
```
<div style='margin-bottom: 0.5em;'></div>
Массив нельзя копировать или перезписывать целиком через оператор присваивания `=` после того, ка кон был создан

По аналогии с переменными, нельзя создавать массив с модификатором `const` без его одновременного заполнения
```cpp
const int arr[5]; // error
const int arr[3] = {1, 2, 3}; // ok
```
<div style='margin-bottom: 0.5em;'></div>
Попытка изменить любой элемент константного массива - ошибка




<h3 style='margin-bottom: 0.5em'>Вычисление размеров массива</h3>
Так как нету встроенной функции поиска длины массива, то используются костыли
<div style='margin-bottom: 0.5em;'></div>
```cpp
int arr[10];
unsigned int size = sizeof(arr) / sizeof(arr[0]);
```





<h3 style='margin-bottom: 0.5em'>Вывод строк наоборот</h3>
```cpp
char arr[][10] = {"qwerty", "asdfg", "zxcvb"};
for (int i = size-1; i>=0; i--){
	int columns = sizeof(arr[0]) / sizeof(arr[0][0])
	
	for (int j = columns-1; j >= 0; j--){
		cout << arr[i][j];
	}
}
```





<h3 style='margin-bottom: 0.5em'>Одномерный массив и указатели</h3>
Так как имя одномерного массива - это константный указатель на первый элемент, то 
<div style='margin-bottom: 0.5em;'></div>
```cpp
int arr[5];
int *p = arr;

arr[3] = 77; // ok
p[3] = 77; // ok
*(p+3) = 77; //ok
*(arr + 3) = 77; // ok

p++; // ok - сдвигаем указатель на 2ой индекс
arr++; // error, т.к. имя массива - это константный указатель
```





<h3 style='margin-bottom: 0.5em'>Обращение к элементам массива</h3>
```cpp
int x;
int arr[10];

x = arr[1]; // ok
x = *(arr+1); // ok, эквивалентно *(1+arr)
x = [1]arr; // error - правильная запись 1[arr]
```




<h3 style='margin-bottom: 0.5em'>Указатель на двумерный массив</h3>
```cpp
int arr[2][3] = {{1, 2, 3}, {4, 5, 6}};
int (*p)[3] = arr; // без круглых скобок `int *p[3] = arr;` мы бы (после расстановки приоритетов операций) имели `int* p[3]` - массив из трех интовых указателей; а так мы указываем на первый элемент и сообщаем, что длина подмассива - 3 символа

arr[1][2] = 7;
p[1][2] = 7;
*(*(p+1)+2) = 7; // *(p+1) - вторая строка массива, а *(second_line + 2) - последний элемент второй строки

arr++; // error, т.к. имя массива - это константный указатель

p++; // сдвигает указатель на целый блок, т.е. с p[0][0] на p[1][0]

```
<div style='margin-bottom: 0.5em;'></div>
```cpp
p = &arr[1]; // указывает на массив 2ой строки
cout << p[0][1]; // 5 - т.к. p[0] указывает на адрес памяти, в котором хранится весь массив {4, 5, 6}, т.к.  p[0] это *(p+0)=*p
```





<h3 style='margin-bottom: 0.5em'>Пример 1</h3>
Задание - прочитать с клавиатуры 5 слов и вывести из них на экрна только те, что начинаются с буквы `d`
<div style='margin-bottom: 0.5em;'></div>
```cpp
int main(){
	const int n = 5;
	char arr[n][100];
	
	for (int i=0; i<n; i++){
	     scanf("%s", arr[i]);
	}
	
	for (int i=0; i<n; i++){
	    if (arr[i][0] == 'd'){
	        printf("%s\n", arr[i]);
	    }
	}
}
```





<h3 style='margin-bottom: 0.5em'>Массивы указателей</h3>
Используются для хранения строк текста, а также динамически создаваемых обьектов, могут быть проинициализированы при определении
```cpp
char * arr1[] = {"one", "two", "three"}; // массив указателей
char arr2[][6] = {"one", "two", "three"}; // массив строк

arr1[0][0]; // ошибка, т.к. arr[0] - это указатель на строку "one"
arr2[0][0]; // ok
```





<h3 style='margin-bottom: 0.5em'>Динамическая память</h3>
Выделяют два оператора управления динамической памятью - область так называемой кучи `heap`

| Процесс             | C                                | C++             |
| ------------------- | -------------------------------- | --------------- |
| Выделение памяти    | `(type*)malloc(sizeof(type)*n);` | `new int;`      |
| Освобождение памяти | `free(arr);`                     | `delete[] arr;` |

```cpp
// *parr - указатель на области памяти с числами int
int *parr = (int*)malloc(sizeof(int) * n); // malloc требует объем выделяемой памяти в байтах

free(parr);

int *parr = new int[n]; // или аналог в cpp
delete parr;
```

*Минусы использования динамической памяти*
- для небольших участков памяти служебная информация будет занимать много места
- на процесс выделения и освобождения памяти тратятся ресурсы
- постоянно выделение и освобождение памяти может привести к фрагментированию
- программист должен быть внимателен и не допускать утечек памяти




<h3 style='margin-bottom: 0.5em'>Ахуенная утечка памяти</h3>
```cpp
char *p = new char;
*p = 'A';

p = 'B'; // мы блять передвигаем ебучий указатель на другую ячейку, а не изменяем его значение
delete[] p;
```




<h3 style='margin-bottom: 0.5em'>Создание одномерного динамического массива</h3>
```cpp
const int n = 5;

int arr[n];
int *p = new int[n];

for (int i=0; i < n; i++){
	p[i] = i; // *(pn+i) = i
}

delete[] pn; // освобождение памяти
```





<h3 style='margin-bottom: 0.5em'>Создание трехмерного динамического массива</h3>
```cpp
int n = 5;

float (*p)[2][3] = new float [n][2][3];
p[0][1][2] = 777;

delete[] p;
```




<h3 style='margin-bottom: 0.5em'>Создание двумерного как одномерного</h3>
```cpp
int n, m

int *arr = new int[n*m];
arr[i*m + j]; // обращение к [i][j] элементу

delete[] arr;
```




<h3 style='margin-bottom: 0.5em'>Двумерный массив из указателей</h3>
```cpp
int n=5, m=7;

int **arr = new int*[n];

for (int i=0; i<n; i++){
	arr[i] = new int[m] // для каждой строки указателей выделяется массив размера m
}

arr[i][j] = 77;


// очистка массива!
for (int i=0; i<n; i++){
	delete[] arr[i]; // удаление памяти от каждой выделенной строки
}


```




<h3 style='margin-bottom: 0.5em'>Изменение размера существующего массива</h3>
```cpp
int n;
int *arr = new int[n];

// заполнение квадратами нахуя-то
for (int i=0; i<n; i++){
	arr[i] = i*i;
}

// создаем новый увеличиваем массив и перекопируем в него все
int *temp = new int[n+10]; 
for (int i=0; i<n; i++){
	temp[i] = arr[i];
}

delete[] arr;
arr = temp;
arr[n+1] = 777;
```
