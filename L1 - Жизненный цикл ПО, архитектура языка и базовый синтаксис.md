<h3 style='margin-bottom: 0.5em;'>Критерии качества программы</h3>
Структура программы влияет на скорость разработки, надежность, возможность легко модифицировать и сопровождать
Количество потребляемых программой ресурсов зависит от эффективности алгоритмов и объема занимаемой памяти
   <div style='margin-bottom: 0.5em;'></div>
По мнению Б. Страуструпа, `C++` создавался с целью, чтобы большую программу можно было структрировать таким образом, чтобы один человек мог работать с большим объемом кода





<h3 style='margin-bottom: 0.5em;'>Структурное программирование</h3>
Это методология разработки, основанная на принципе программирования "сверху-вниз". При этом код имеет четкую структуру и хорошо читаем
   <div style='margin-bottom: 0.5em;'></div>
Разбиение на файлы помогает улучшить структуру программы и, при правильном разбиении, уменьшить общее время получения нового исполняемого модуля
   <div style='margin-bottom: 0.5em;'></div>
Для обеспечения модульности в `C++` представлена возможность компиляции (перевода кода в машинный) каждого файла по отдельности и последующую стыковку в единый `.exe`

<h3 style='margin-bottom: 0.5em;'>Препроцессор</h3>
Это текстовый редактор, который автоматически запускается перед этапом компиляции. Результат его работы - один большой файл с исходным текстом программы, в котором объединены все части кода с помощью текстовой подстановки
   <div style='margin-bottom: 0.5em;'></div>
Полученный файл называется единицей компиляции. И далее он поступаем на вход компилятору




<h3 style='margin-bottom: 0.5em;'>Компиляция</h3>
Включает в себя лексический и синтаксический анализы, трансляцию
   <div style='margin-bottom: 0.5em;'></div>
Результатом работы компилятора является промежуточный объектный файл, имеющий расширение `.obj` или `.o`
<div style='margin-bottom: 0.5em;'></div>
Обычно именно на этой стадии легко находятся синтаксические ошибки - на них указывает компилятор




<h3 style='margin-bottom: 0.5em;'>Компоновка</h3>
На этом этапе соединяются все раннее откомплированный части. Все модули обрабатываются одновременно для распределения памяти и формирования адресных частей
<div style='margin-bottom: 0.5em;'></div>
Ошибки этапа компановки - неразрешенные внешние зависимости. Такие ошибки находятся трудно, т.к. не указывается конкретный файл, в котором произошла ошибка




<h3 style='margin-bottom: 0.5em;'>Конструкции языка</h3>
- `int x;` - обычная переменная целочисленного типа
- `int *x;` / `int* x;` / `int * x;` - указатель на целое число
- `int x[10];` - массив из 10 целых чисел, доступ к элементам от `x[0]` до `x[9]`
- `int* x[10];` - массив из 10 указателей, каждый элемент - указатель на какое-то целое число
- `int* (*x)(int);` - указатель на функцию, где переменная `x` - это адрес функции, которая принимает аргумент типа `int` и возвращает указатель на `int` (`int*`)




<h3 style='margin-bottom: 0.5em;'>Функции</h3>
В теле программы *всегда* должна быть описана одна функция с именем `main` - она не генерируется автоматические
<div style='margin-bottom: 0.5em;'></div>
Общая стуктура функций
``` cpp
тип_возвращаемого_значения имя_функции(параметры)
{
    // 1. Локальные для этой функции данные
    
    // 2. Код функции (может работать с переданными параметрами, 
    //    локальными и внешними данными)
    
    // 3. Вызов других функций
}
```

<h3 style='margin-bottom: 0.5em;'>L-value и R-value</h3>
*L-value* - конструкция, которая может быть использована слева от знака равенства. Проще говоря, *l-value* - любое выражение, результат которого компилятор ассоциирует с выделенной памятью, а в его роли может выступать переменная, либо сложная конструкция
*R-value* - все, что может находиться справа от знака равенства, например - константы
<div style='margin-bottom: 0.5em;'></div>
*Допустимые выражения*
- `x = <expression>;`
- `*f() = <exp>;`
- `x = y = <exp>;` (причем здесь как в python переменные не будут ссылаться на одну и ту же ячейку памяти)
<div style='margin-bottom: 0.5em;'></div>
*Но запрещается*
- `x + y = <exp>;`
- `10 = <exp>;`




<h3 style='margin-bottom: 0.5em;'>Области видимости</h3>
Для обращения к глобальной переменной используется конструкция `::x`
<div style='margin-bottom: 0.5em;'></div>
```cpp
int i = 1; // глобальная переменная

void func()
{
    int i = 2; // локальная переменная функции proc()
    {
        int i = 3; // локальная переменная внутреннего блока
        
        // в с++ для вывода в стиле си:
        printf("\n global i=%d, local i=%d", ::i, i); // global i=1, local i=3
        
        // в чистом стиле с++ (через std::cout):
        std::cout << "\n global i=" << ::i << ", local i=" << i; 
    } 
}
```




<h3 style='margin-bottom: 0.5em;'>Операции языка</h3>
Далее в таблицах последовательно представлены *унарные* и  *бинарные операции*

|   Оператор   | Что делает (Кратко)                            | Пример в коде             |
| :----------: | :--------------------------------------------- | :------------------------ |
|   **`-`**    | Меняет знак числа на противоположный           | `int x = -5;`             |
|   **`~`**    | Инвертирует все биты (0 на 1, 1 на 0)          | `bits = ~flags;`          |
|   **`!`**    | Превращает *истину* во *ложь* и наоборот       | `if (!isReady)`           |
|   **`*`**    | Получает значение по адресу (указателю)        | `int val = *ptr;`         |
|   **`&`**    | Возвращает адрес переменной в памяти           | `int* ptr = &x;`          |
| **`sizeof`** | Возвращает размер типа или переменной в байтах | `size_t s = sizeof(int);` |
|   **`+`**    | Сохраняет знак числа (редко используется)      | `int x = +5;`             |
|   **`++`**   | Увеличивает значение переменной на 1           | `x++;` или `++x;`         |
|   **`--`**   | Уменьшает значение переменной на 1             | `x--;` или `--x;`         |

|    Оператор     | Что делает (Кратко)                                  | Пример в коде                  |
| :-------------: | :--------------------------------------------------- | :----------------------------- |
|     **`*`**     | Умножение двух чисел                                 | `int area = w * h;`            |
|     **`/`**     | Деление (для `int` — целочисленное)                  | `int cells = 10 / 3; // 3`     |
|     **`%`**     | Остаток от деления (только для `int`)                | `int rem = 10 % 3;   // 1`     |
|     **`+`**     | Сложение двух чисел                                  | `int sum = a + b;`             |
|     **`-`**     | Вычитание двух чисел                                 | `int diff = a - b;`            |
|    **`<<`**     | Побитовый сдвиг влево (умножение на 2)               | `int x = 5 << 1;     // 10`    |
|    **`>>`**     | Побитовый сдвиг вправо (деление на 2)                | `int x = 4 >> 1;     // 2`     |
|     **`<`**     | Проверка: меньше                                     | `if (a < b)`                   |
|     **`>`**     | Проверка: больше                                     | `if (a > b)`                   |
|    **`<=`**     | Проверка: меньше или равно                           | `if (a <= b)`                  |
|    **`>=`**     | Проверка: больше или равно                           | `if (a >= b)`                  |
|    **`==`**     | Проверка: строго равно                               | `if (a == b)`                  |
|    **`!=`**     | Проверка: не равно                                   | `if (a != b)`                  |
|     **`&`**     | Побитовое И (AND) — маскирование                     | `int res = flags & 1;`         |
|   **$\mid$**    | Побитовое ИЛИ (OR) — установка битов                 | `int res = flags \| 2;`        |
|     **`^`**     | Побитовый XOR — инверсия/переключение                | `int res = flags ^ 4;`         |
|    **`&&`**     | Логическое И (AND) — оба условия истинны             | `if (isReady && isOpen)`       |
| **$\mid \mid$** | Логическое ИЛИ (OR) — хоть одно истинно              | `if (hasCard \|\| hasCash)`    |
|     **`,`**     | Вычисляет выражения по очереди, возвращает последнее | `for (int i = 0, j = 10; ...)` |

*Тернарный оператор* (оба исходы должны возвращать одинаковый тип)
<div style='margin-bottom: 0.5em;'></div>
```cpp
// переменная условие ? выражение_если_истина : выражение_если_ложь
const char* status = age >= 18 ? "adult" : "child"; 
// строка - указатель на массив символов
```

Он может выступать и *l-value* (только в `cpp`!)
``` cpp
(exp ? x : y) = 99;
```



<h3 style='margin-bottom: 0.5em;'>Приоритеты операций</h3>
Операции с присваиванием раскрываются справа налево: `a = b = c` эквивалентно `a = (b = c)`, тернарные операторы также являются правоассоциативными
<div style='margin-bottom: 0.5em;'></div>
Остальные операции (сложение, умножение, сравнение) левоассоциативные: `a + b + c` эквивалентно `(a + b) + c`
