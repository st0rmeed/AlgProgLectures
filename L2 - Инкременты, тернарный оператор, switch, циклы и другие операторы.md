<h3 style='margin-bottom: 0.5em;'>Что выведет код?</h3>
``` cpp
float x = -0.1, y = -0.05, z = 0.5;
cout << (x < y < z) << endl;
```
<div style='margin-bottom: 0.5em;'></div>
Ответ: `0`, потому что результатом выполнения операции `x < y` будет `1`; а дальше будет проверка `1 < z`, т.е. `1 < 0.5` $\to$ `0`




<h3 style='margin-bottom: 0.5em;'>Инкременты, операции присвоения</h3>
Любой из двух инкрементов (пост/префикс) требует на вход `l-value` переменную, они не работают с `r-value`

Результат префиксного инкремента `++x` - это `l-value`, а результат постфиксного инкремента - это не `l-value`
<div style='margin-bottom: 0.5em;'></div>
Причина: когда мы пишем `i++`, оператор должен 
вернуть *старое* значение переменной, но при этом саму переменную уже увеличить; поэтому язык возвращает *временную копию* старого значения, а любая вреграфеменная копия - это r-value
<div style='margin-bottom: 0.5em;'></div>
``` cpp
(x++)++; // ошибка компиляции, т.к. `x++` возвращает r-value, а внешний инкремент можно применять только к l-value
```
<div style='margin-bottom: 0.5em;'></div>
``` cpp
(++x)++; // успешная компиляция, т.к. `++x` увеличивает `x` и возвращает его же как l-value
```
<div style='margin-bottom: 0.5em;'></div>
``` cpp
++(++x); // успешная компиляция; x += 2
```
<div style='margin-bottom: 0.5em;'></div>
``` cpp
z = x +++ y; // скопилируется, эквивалент записи `z = (x++) + y;`,
// т.к. компилятор использует правило жадного поглощения слева-направо и сгруппирует символы в максимально длинный возможный токен 
``` 
<div style='margin-bottom: 0.5em;'></div>
``` cpp
z = x +++++ y; // ошибка компиляции
// запись эквивалентна `z = ((x++)++) + y;` а (x++)++ - ошибка
```




<h3 style='margin-bottom: 0.5em;'>Пример 1</h3>
``` cpp
y = 3*(x=5 + (z=7)) + 1; // успешная компиляция, т.к. операция присвоения `=` возвращает записанное в переменную значение
```




<h3 style='margin-bottom: 0.5em;'>Пример 2</h3>
```cpp
a *= b += c; // успешная компиляция
// как и обычное присваивание, операция составного присваивания обладают правой ассоциативностью
// эта строка эквивалентна `a = a * (b + c)`
```





<h3 style='margin-bottom: 0.5em;'>Оператор switch</h3>
Общая структура оператора
<div style='margin-bottom: 0.5em;'></div>
```cpp
switch (expression)
{
	case const1:
		exp1;
	case const2:
		exp2;
	default:
		exp_def;
}
```
<div style='margin-bottom: 0.5em;'></div>
После выполнения одной из ветвей `case`, управление передается в следующую ветвь, поэтому для выхода из switch необходимо использовать один из следующих операторов: `break`/`goto <метка>`/`continue`/`return`
Это и есть мехнизм `fall-through` - мы будем проваливаться по всему `case` до самого низа, пока не встретим оператор остановки




<h3 style='margin-bottom: 0.5em;'>Тернарный оператор</h3>
Общий вид
<div style='margin-bottom: 0.5em;'></div>
``` cpp
(condition)? expression1 : expression2;
```
<div style='margin-bottom: 0.5em;'></div>
Тернарный оператор не только присваивает значение переменным, но и возвращает его, поэтому он может выступать как в роли `l-value`, так и в роли `r-value`

Тернарный оператор может быть вложенным
<div style='margin-bottom: 0.5em;'></div>
``` cpp
(cond1)? exp1 : (cond2)? exp2 : exp 3
```
<div style='margin-bottom: 0.5em;'></div>




<h3 style='margin-bottom: 0.5em;'>Условные операторы</h3>
Если результат логического выражения используется в арифмитическом выражении, то вместо `false` компилятор подставит `0`, а вместо `true` - `1`




<h3 style='margin-bottom: 0.5em;'>Пример 3</h3>
```cpp
int x = -1, y = 1;
if (++x && --y) // не выполниться, т.к. `++x` = 1
// x = 0; y = 1 (!!)
// т.к. произойдет 'короткое замыкание' - в целях оптимизации `c++` не станет продолжать высчитывать выражение, т.к. в левой части and находится 0 
```




<h3 style='margin-bottom: 0.5em;'>Оператор ","</h3>
Запятая имеет самый низкий приоритет выполнения среди всех операторов
<div style='margin-bottom: 0.5em;'></div>
``` cpp
int a = 1, b = 2, c = 3;
x = a++, b++, c++ // 1, т.к. по приоритетам это эквивалентно следующей записи (x = a++), b++, c++; крайние идут на выброс

x = (a++, b++, c++) // 3, т.к. именно это число возвращается последним
```




<h3 style='margin-bottom: 0.5em;'>Операторы циклов</h3>
Цикл в языке `c`/`c++` могут быть описаны одним из 3-х следующих способов:
<div style='margin-bottom: 0.5em;'></div>
```cpp
while (condition) {expression}

do {exp} while (condition) // цикл с постусловием, который гарантированно выполниться хотя бы 1 раз

for (variable; condition; operation) {exp}
```





<h3 style='margin-bottom: 0.5em;'>Цикл for</h3>
Последовательность выполнения операторов при реализации цикла
1. Операторы 1-ой части заголовка (до первой `;`) выполняются один раз до входа в цикл)
2. Операторы 2-ой части (проверка условия и выход из цикла в случае его нарушения) проверяются на каждой итерации
3. Операторы 3-ей части заголовка (что делаем с итерируемой переменной) выполняются на каждой операции
4. Переход к пункту 2




<h3 style='margin-bottom: 0.5em;'>Бесконечные циклы</h3>
Рассмотрим следующие записи, каждая из низ корректна и представляет из себя бесконечный цикл
<div style='margin-bottom: 0.5em;'></div>
```cpp
for( ; ; ){ // pk, эквивалентна for(;;){}
}
```
<div style='margin-bottom: 0.5em;'></div>
```cpp
while(true){ // ok, эквивалент while(1){}
}
```
<div style='margin-bottom: 0.5em;'></div>
```cpp
do{exp} while(true) // ok
```
