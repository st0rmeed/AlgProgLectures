<h3 style='margin-bottom: 0.5em;'>Литералы</h3>
Литерал - это значение, которое записано в тексте программы как есть (например, `5`, `3.14`, `name`). А константа - это именнованная ячейка памяти (переменная), значение которой запрещено менять




<h3 style='margin-bottom: 0.5em;'>Целочисленные и вещественные литералы</h3>
Способы хранения литералов
- `int` - если значение помещается в диапазон этого типа, т.е. 2 байт
- `long int` - если значение выходит за пределы диапазона `int`
- `long long int` - если значение выходит за пределы `long int`
- иначе - значение отсекается до 8 байт
<div style='margin-bottom: 0.5em;'></div>
Если константа помещается в диапазон знакового числа, то она записывается как знаковое число. Иначе она трактуется как беззнаковая

При этом программист с помощью суффиксов может указывать компилятору, какой тип данных следует выдать данному литералу
- `L` - `long int`
- `LL` - `long long int`
- `U` - `unsigned int`
<div style='margin-bottom: 0.5em;'></div>
Суффиксы можно комбинировать, например литерал `123456789ULL` будет храниться как `unsigned long long int`

По умолчанию, все литералы с плавающей точкой относятся к типу `double`, но с помощью суффика `f` их можно привести к типу `float`




<h3 style='margin-bottom: 0.5em;'>Строковые литералы</h3>
Строковый литерал - это массив, в котором компилятор хранит коды указанных программистом символов. При генерации таких массивов компилятор автоматически добавляет заверщающий нулевой байт `\0` - он означает конец строки и необходим для функций, осуществляющих вывод строк для понимания конца, потому что сам по себе литерал не знает своих размеров
<div style='margin-bottom: 0.5em;'></div>
Строка может быть пустой, а строковые литералы могут конкатенироваться: "12" "34" эквивалентно "1234"
<div style='margin-bottom: 0.5em;'></div>
Строка с префиксом `L` считается строкой `uncicode`, например: `L"Вася"`
<div style='margin-bottom: 0.5em;'></div>
Длинные строки можно переносить с помощью символа `\`




<h3 style='margin-bottom: 0.5em;'>Перечисления</h3>
Перечисляемый тип `enum` эквивалентен `signed int` и обьявляется так
<div style='margin-bottom: 0.5em;'></div>
```cpp
enum Name {
	name1 = 1,
	name2 = 2,
};
```
<div style='margin-bottom: 0.5em;'></div>
```cpp
enum Colors{
	RED, // 0
	GREEN, // 1
	BLUE = 5, // 5
	YELLOW // 6
}
Colors color = RED; // `color = 1` - ошибка, т.к. переменная не int
int x = color; // 1

if (color == RED){
	// do()
}
```





<h3 style='margin-bottom: 0.5em;'>Ключевое слово `typedef`</h3>
Имя `typedef` - это сокращение от `type definintion`, оно позволяет создавть псевдонимы для уже существующих типов (не создавая новый тип!)
<div style='margin-bottom: 0.5em;'></div>
```cpp
typedef unsigned long long int byte;
typedef byte new_byte; // создаст еще один псевдоним для типа `unsigned long long int`

unsigned long long int n1 = 0;
byte n2 = 0;
new_byte n3 = 0; // для компилятора все переменные одного типа
```
<div style='margin-bottom: 0.5em;'></div>
```cpp
typedef enum {
	OK,
	ERROR,
	PENDING
} Status;

Status stat = OK; // `enum` теперь `Status`
```
