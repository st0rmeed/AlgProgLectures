<h3 style='margin-bottom: 0.5em;'>Проcстранство имен</h3>
Служит для группировки переменных, функций и так далее
<div style='margin-bottom: 0.5em;'></div>
```cpp
namespace name
{
	var1;
	var2;
	func1;
	func2;
};
```
<div style='margin-bottom: 0.5em;'></div>
Для обращения к переменной из пространства имен используется оператор `::`

Следующий пример объявляет 3 абсолютно разных переменных
<div style='margin-bottom: 0.5em;'></div>
```cpp
namespace space1{
	int x;}
namespace space2{
    int x;}
int x;    

int main(){
	space1::x = 1;
	space2::x = 2;
	x = 3;
}
```




<h3 style='margin-bottom: 0.5em;'>Директива `using`</h3>
Позволяет обращаться к элементам простарнства напрямую, без упоминания библиотеки
<div style='margin-bottom: 0.5em;'></div>
```cpp
using namespace std;
cout << "text"
```

Из простарнства имен можно импортировать только одну функцию
<div style='margin-bottom: 0.5em;'></div>
```cpp
using std::cout;
cout << "text"
```

Но отсюда вытекает и проблема, возникающая в результате совпадения имен переменных из разных пространств
<div style='margin-bottom: 0.5em;'></div>
```cpp
namespace space {
    int x;}
int x; // глобальная переменная

using namespace space;
x = 0 // ошибка
```

Но иная кратина будет наблюдаться с локальной переменной
<div style='margin-bottom: 0.5em;'></div>
```cpp
namespace space{
    int x;}
    
int main(){
	int x;
	x = 10 // ok, локальная переменная изменится
}
```




<h3 style='margin-bottom: 0.5em;'>Директива препроцессора</h3>
*Правила для директив препроцессора*
- должна начинаться с `#`
- пишутся на каждой строчке отдельно, для продолжения на другой строке можно использовать символ `\`
- большинство директив можно использовать в любом месте файла

*Директивы препроцессора*
- `#include` - вставляет содержимое файла в текущее место в коде, причем нужно использовать `< >` для стандартных файлов и `" "` для кастомных
- `#define`/`#undef` - создание и удаление макроса
- `#if`/`#elif`/`#else`/`#endif` - проверка условий, которые (в отличии от обычного `if`/`else`) известны еще до запуска программа, в момент когда компилятор собирает код; чаще всего проверяется тип ОС, определен ли конкретный макрос и какое-то математическое выражение
- `ifdef`/`ifndef` - проверка на то, определен ли какой-то макрос в программе
- `#pragma once` - гарантирует, что файл, в котором написана эта строка, будет подключен ровно один раз (даже при множественном подключении со сложными схемами через множество файлов-вкладышей), защищает от ошибок двойного объявления
- `#line i "file.cpp"`  - меняет номер текущей строки и имя файла во внутреннем счетчике компилятора (с этой строки компилятор будет думать, что он на `i`ой строке файла `file.cpp`)
- `#error "text"` - останавливает компиляцию и выводит в консоль ошибку `text` 




<h3 style='margin-bottom: 0.5em;'>Директива `#define`</h3>
Позволяет программисту создавать макросы, которые компилятор потом подставляет в код программы. Макросы могут быть с параметрами, например
<div style='margin-bottom: 0.5em;'></div>
```cpp
#define SQUARED(x) ((x)*(x))
int num = SQUARE(5) // 25
```

Используя сочетание `##` можно соединять несколько лексем в одну
<div style='margin-bottom: 0.5em;'></div>
```cpp
#define NICK(name, number) (name##number)
int NICK(vasia, 1) = 1; // int vasia_1 = 1;
```

Существуют предопределенные макросы
- `__DATE__` - дата компиляции файла
- `__FILE__` - полный путь (имя) текущего файла, откуда вызван макрос
- `__LINE__` - номер строки, в которой написан макрос
- `__TIME__` - время начала компиляции файла




<h3 style='margin-bottom: 0.5em;'>Диагностический макрос `assert`</h3>
Если значение в макросе равно `0`, то макрос останавливает программу и выводит диагностику с указанием файла и номером строки, использование:
<div style='margin-bottom: 0.5em;'></div>
```cpp
assert(x < 0);
```




<h3 style='margin-bottom: 0.5em;'>Указатели</h3>
Существуют указатели на переменные, указатели, массив и функции
Программист, задавая тип указываемого объекта, сообщает компилятору, как тот должен интерпретировать этот дарес. Количество байт, выделяемых под указатель, не зависит от объекта (потому что в любом случае мы храним адрес)
<div style='margin-bottom: 0.5em;'></div>
Использование указателя до его инициализирования - ошибка
<div style='margin-bottom: 0.5em;'></div>
Память под указатель может быть выделена в стеке, куче или статической области (в зависимости от того, где расположен объект, на который ссылается указатель)
<div style='margin-bottom: 0.5em;'></div>
Оператор `&` можно применять только к `l-value` переменной
<div style='margin-bottom: 0.5em;'></div>
Сложения, умножения и деления уакзателей запрещены




<h3 style='margin-bottom: 0.5em;'>Указатель типа void*</h3>
Такой указатель может ссылаться на переменную любого типа
<div style='margin-bottom: 0.5em;'></div>
```cpp
int n = 1;
char c = 'a';

void *p;
p = &n; // ok
p = &c; // ok
```
<div style='margin-bottom: 0.5em;'></div>
Однако, через указатель типа `void` нельзя вычислить размер того, на что он ссылается, потому что void - неопределенность (но такое бы прокатило с указателямями других типов)




<h3 style='margin-bottom: 0.5em;'>Константные указатели</h3>
С помощью слова `const` можно создавать константные указатели  и указатели на константные значения, а также их комбинированный вариант
<div style='margin-bottom: 0.5em;'></div>
```cpp
const int *p1; // указатель на константу
int *const *p2; // константный указатель
const int *const p3// константный указатель на константу
```
