<h3 style='margin-bottom: 0.5em;'>Размещение переменных</h3>
Способ размещения переменной в памяти зависит от контекста определеняи переменной и использования дополнительных ключевых слов

***Основные места***
- статическая память
- автоматическая память
- динамическая память
- регистровая память - небольшая и очень быстрая память, расположенная внутри процессора и предназначенная для выполнения арифметических/логических операций




<h3 style='margin-bottom: 0.5em;'>Статическая память</h3>
Это память, в которую компилятор помещает объекты, существующие во время всего выполнения программы. В ней содержаться:
- глоабльные переменные
- переменные из пространств имен `namespace`
- статические переменные `static`




<h3 style='margin-bottom: 0.5em;'>Автоматическая память</h3>
Память, в которуй по умолчанию располагаются локальные переменные, определенные внутри любого блока кода `{}` или параметры функции
<div style='margin-bottom:0.5em;'></div>
Для таких перменных компилятор автоматически отводит и освобождает место в стеке `stack` (`LIFO` - *last in, first out*). Переменные существуют до завершения области видимости блока




<h3 style='margin-bottom: 0.5em;'>Динамическая память</h3>
Для размещения переменных программист должен явно запрашивать такую память и самостоятельность освобождать ее вручную по мере необходимости. Такая память называется кучей (`heap`) и она работает медленней, чем `stack`, потому что 
- сложно искать свободные куски памяти
- возможна проблема фрагменации, когда память выглядит блять как сыр
- возможна пролбема синхронизации между потоками (т.е. когда сразу несколько команд обращаются к одной ячейке)




<h3 style='margin-bottom: 0.5em;'>Неявная инициализация переменных</h3>
При неявной инициализации переменных (т.е. записи`int a;`/`char c;`), переменные создаются со следующими значениями 
- статические `static` создаются с нулем
- автоматические имеют случайно значение области стека, где выделена память
- динамические имеют случайное значение из кучи




<h3 style='margin-bottom: 0.5em;'>Ключевое слово `static`</h3>
 Компилятор размещает такую переменную в статической памяти и инициализирует ее только один раз (далее такие строки с инициализацией он попросту игнорирует)
 <div style='margin-bottom: 0.5em;'></div>
 ```cpp
for (int i=0; i < 3; i++){
	int n1 = 1;
	static int n2 = 33;
	n1++;
	n2++;
}

// i=0: n1 = 2, n2 = 33
// i=1: n1 = 2, n2 = 34
// i=2: n1 = 2, n3 = 35
 ```




<h3 style='margin-bottom: 0.5em;'>Ключевое слово `const`</h3>
При инициализации такой переменной обязательно должно быть указано ее значение, а в ходе выполнения программы оно не может быть изменено
 <div style='margin-bottom: 0.5em;'></div>
В `c` память, зарезерированная под константную переменную, доступна только для чтения
<div style='margin-bottom: 0.5em;'></div>
В `cpp` компилятор в большинстве случаев не будет отводить память под константную переменную, а будет просто подставлять значение переменной непосредственно в местах обращения в ней
<div style='margin-bottom: 0.5em;'></div>
```cpp
const int n=1;
n = 5; // ошибка компиляции
```




<h3 style='margin-bottom: 0.5em;'>Неявное приведние типов</h3>
Не стоит смешивать в операторах сравнения знаковые и беззнаковые операнды, а также операнды различных типов
<div style='margin-bottom: 0.5em;'></div>
```cpp
int x = -1; // в двоичной системе 11
unsigned int y = 1; // `01`
cout << (x < y); // false
```
<div style='margin-bottom: 0.5em;'></div>
```cpp
char c1 = 0xff; // переполнение, все единицы, поэтому -1
unsigned char c2 = 0xff; // 255
cout << (c1 == c2); // false
```
<div style='margin-bottom: 0.5em;'></div>
```cpp
int n = 0xff; // 255
char c = 0xff; // вес 1 байт, переполнение, поэтому `-1`
cout << (c == n); // false
```




<h3 style='margin-bottom: 0.5em;'>Явное приведние типов</h3>
При явном приведении типов ответственность за результат ложиться на программиста
<div style='margin-bottom: 0.5em;'></div>
```cpp
int x = 1, y = 2;
double z = (double) x/y; // 0.5, т.к. операция `(double)` имеет приоритет выше, то сначала будет приведение типов
```
<div style='margin-bottom: 0.5em;'></div>
```cpp
int x = 1, y = 2; // антипример
double z = (double) (x/y); // 0.0
double v = x/y; // 0.0
```




<h3 style='margin-bottom: 0.5em;'>Преобразование типов в стиле `C++`</h3>

| Способ                              | Проверка типов                                 | Описание                                                  | Ограничения                                                                                                                       |
| ----------------------------------- | ---------------------------------------------- | --------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| **`static_cast<type>(expression)`** | С проверкой типов на этапе компиляции          | Стандартные преобразованийя (например, `int` в `double`). | Ошибка при попытке преобразовать несовместимые типы (`int` в `char`)                                                              |
| **`reinterpret_cast<type>(exp)`**   | Без проверки типов                             | Отсутствие защиты, преобразование в лоб                   |                                                                                                                                   |
| **`const_cast<type>(exp)`**         | С проверкой типов (он должен остаться прежним) | Не меняет тип данных, меняет право редактирования         | Снимать константность можно только с объектов, которые изначально создавались как неконстантные; иначе - неопределенное поведение |

```cpp
int x = 1 , y = 2;

double z1 = static_cast<double>(x)/y // 0.5, т.к. делим 1.0 на 2
double z2 = static_cast<double>(x/y) // 0.0
```
<div style='margin-bottom: 0.5em;'></div>
```cpp
char c = -1;
int y = c1; // -1
int z = static_cast<unsigned_char>(x) // 255
```




<h3 style='margin-bottom: 0.5em;'>Побитовые операции</h3>
- `~` - меняем биты на противоположенные
- `|` - логическое ИЛИ между двумя битами
- `&` - логическое И
- `^` - исключающее или `xor`; дает `1` только когда биты различаются
- `x >>= n` - сдвиг влево/вправо на `n` разрядов
<div style='margin-bottom: 0.5em;'></div>
Операция `&` часто используется для снятия битов, а `|` - для их установки
